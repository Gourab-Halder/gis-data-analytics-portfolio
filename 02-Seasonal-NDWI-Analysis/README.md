# Seasonal Wetland Dynamics Using NDWI (2005–2025)

## Project Overview

This project examines the seasonal and temporal dynamics of wetland and surface water conditions in the Chalan Beel region of Bangladesh using the Normalized Difference Water Index (NDWI).

## Objectives

- Examine seasonal water distribution across different years.
- Compare wetland conditions during July, August, September, and October.
- Identify temporal changes in surface water conditions.
- Understand the seasonal variability of wetland extent.

## Temporal Coverage

Five selected years:
- 2005
- 2010
- 2015
- 2020
- 2025

Four months for each year:
- July
- August
- September
- October

Total map outputs: 20

## Methodology

- Landsat satellite imagery processing.
- NDWI calculation.
- Monthly water condition mapping.
- Temporal and seasonal comparison.

## Tools Used

- Google Earth Engine
- ArcMap

## Project Outputs

Twenty monthly NDWI maps covering five selected years.

## Study Area

Chalan Beel, Bangladesh.
