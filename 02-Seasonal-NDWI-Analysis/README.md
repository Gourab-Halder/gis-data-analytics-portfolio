
# Seasonal Wetland Dynamics Using NDWI (2005–2025)

## Project Overview

This project examines seasonal and temporal variations in surface water conditions across the Chalan Beel region of Bangladesh using the Normalized Difference Water Index (NDWI).

The analysis covers five selected years (2005, 2010, 2015, 2020, and 2025) to investigate changes in seasonal water distribution and wetland conditions.

## Study Area

**Chalan Beel, Bangladesh**

## Data Sources

- Landsat satellite imagery
- Google Earth Engine satellite data processing

## Tools Used

- Google Earth Engine (GEE)
- ArcMap
- Microsoft Excel

## Temporal Coverage

- Selected years: 2005, 2010, 2015, 2020, 2025
- Observation months: July, August, September, October
- Total map outputs: 17

## Methodology

1. Landsat satellite imagery processing.
2. Normalized Difference Water Index (NDWI) calculation.
3. Monthly water condition mapping.
4. Seasonal and inter-annual spatial comparison.

## Project Outputs

- NDWI maps for five selected years.
- Monthly water condition maps.
- Seasonal comparison of surface water distribution.
- Spatial representation of wetland dynamics.
