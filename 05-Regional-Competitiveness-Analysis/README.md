# Regional Competitiveness and Spatial Interaction Analysis

## Project Overview

This project examines regional competitiveness and spatial interaction across 16 districts of northern Bangladesh. It combines regional competitiveness assessment, centrality analysis, and the Gravity Model to explore differences in district-level development and patterns of interaction between districts.

## Project Objectives

- Assess the relative competitiveness of the selected districts.
- Examine the centrality of districts based on available facilities and services.
- Analyse potential spatial interactions between districts using the Gravity Model.
- Interpret regional development patterns through quantitative and spatial analysis.

## Methodology

The analysis applies three main approaches:

1. **Regional Competitiveness Index (RCI):** Used to assess the relative competitiveness of the selected districts.
2. **Marshall’s Centrality Index:** Applied to examine the centrality of districts based on the distribution of facilities and services.
3. **Gravity Model:** Used to explore potential spatial interactions between districts.

## Study Area

Sixteen districts of northern Bangladesh.

## Tools and Data

- **Software:** Microsoft Excel and QGIS
- **Data sources:** Bangladesh Bureau of Statistics (BBS), BANBEIS, and OpenStreetMap (OSM), where applicable.
