# District-Level Inequality and Competitiveness Analysis

## Project Overview

This project examines district-level inequality and regional competitiveness across 16 districts of northern Bangladesh. It applies the Theil Index and Regional Competitiveness Index (RCI) to explore differences in economic and regional development. The project also develops a combined analytical classification to examine how inequality and competitiveness vary across districts.

## Project Objectives

- Examine the distribution of inequality across the selected districts.
- Assess district-level regional competitiveness.
- Compare inequality and competitiveness patterns.
- Classify districts based on the combined analytical dimensions.

## Methodology

The analysis uses three main approaches:

1. **Theil Index:** Applied to examine the distribution of inequality.
2. **Regional Competitiveness Index (RCI):** Used to assess the relative competitiveness of districts.
3. **Combined Classification:** Used to group districts according to their inequality and competitiveness characteristics.

## Study Area

Sixteen districts of northern Bangladesh.

## Tools and Data

- **Software:** Microsoft Excel and QGIS
- **Data sources:** Bangladesh Bureau of Statistics (BBS), BANBEIS, and OpenStreetMap (OSM), where applicable.
