
# Land Use and Land Cover Change Analysis of Chalan Beel (2005–2025)

## Project Overview

This project examines land use and land cover (LULC) changes in the Chalan Beel region of Bangladesh over a 20-year period (2005–2025).

The analysis focuses on four major land use and land cover categories: wetland, agriculture, vegetation, and built-up areas.

## Study Area

**Chalan Beel, Bangladesh**

## Objectives

- Identify major land use and land cover categories.
- Examine spatial changes between 2005 and 2025.
- Assess changes in wetland and agricultural areas.
- Understand the implications of land use change for wetland ecosystems.

## Data Sources

- Landsat satellite imagery (2005–2025).
- Supporting spatial datasets for the study area.

## Tools Used

- Google Earth Engine (GEE)
- ArcMap
- Microsoft Excel

## Classification Categories

1. Wetland
2. Agriculture
3. Vegetation
4. Built-up Area
