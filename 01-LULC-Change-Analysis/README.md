# Land Use and Land Cover (LULC) Change Analysis of Chalan Beel (2005–2025)

## Project Overview

This project examines land use and land cover changes in the Chalan Beel wetland region of Bangladesh over a 20-year period (2005–2025).

The analysis focuses on the changing distribution of wetland, agricultural land, vegetation, and built-up areas.

## Objectives

- Identify major land use and land cover categories.
- Examine spatial changes between 2005 and 2025.
- Understand the expansion of agricultural and built-up areas.
- Assess the implications of land use change for wetland ecosystems.

## Study Area

Chalan Beel, Bangladesh.

## Data Sources

- Landsat satellite imagery (2005–2025).
- Supporting spatial datasets for the study area.

## Methodology

- Satellite image processing using Google Earth Engine.
- Supervised land use and land cover classification.
- Classification into four categories:
  - Wetland
  - Agriculture
  - Vegetation
  - Built-up Area
- Spatial analysis and map preparation using ArcMap.

## Tools Used

- Google Earth Engine
- ArcMap
- Microsoft Excel

## Project Outputs

- LULC maps for selected years.
- Spatial representation of land use transitions.
- Area-based comparison of LULC categories.
- Research findings and environmental interpretation.

## Limitations

The classification was conducted using the available satellite imagery and supervised classification approach. Independent accuracy assessment was not conducted.
